# Assist: working together, live — a Porta plugin

Work on one project together, live: a host shares it over the network, guests join, everyone edits the same files and sees each other's carets.

This is `janalis/porta-assist`, one of the plugins bundled with
[Porta](https://github.com/janalis/porta), the terminal IDE for PHP. Porta
ships it already: turn it on under **Settings → Plugins**. Install this
package only to run a copy of your own, which shadows the bundled one.

- [Documentation](https://janalis.github.io/porta/plugins/assist/)
- [Writing a plugin](https://janalis.github.io/porta/plugins)
